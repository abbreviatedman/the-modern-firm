## 1. Executive Summary

This proposal outlines a services engagement in which **[Your Company]** will:

1. Design, build, and support a live-updating Dash web application that presents performance data to **[Sales Company]** and its clients (charter schools).
2. Operate and maintain an API layer that serves dashboard data.
3. Deliver recurring analytics reports evaluating lead efficacy by lead source, demographics, and geography.

The business objective is to provide transparent, data-driven visibility into lead generation and conversion performance from outreach to student applications.

## 2. Parties and Purpose

This agreement is between:

- **Provider:** [Your Data Analysis Company Legal Name], a data analytics and software services company.
- **Client:** [Sales Company Legal Name], a sales and outreach organization that supports charter school client enrollment pipelines.

Purpose: to provide a live reporting dashboard and ongoing analytical reporting based on Client data and Provider API services.

## 3. Definitions

- **Lead:** A prospective student contact captured by Client outreach efforts.
- **Lead Source:** The origination channel for a lead, including at minimum social media and canvassing.
- **Lead Status:** A defined stage in the lead lifecycle (for example: New, Contacted, Qualified, Application Started, Applied).
- **Application:** A submitted enrollment application to a charter school client.
- **Dashboard:** The web application built using Dash and related components.
- **API Services:** Provider-maintained endpoints and services delivering normalized dashboard data.
- **End Clients:** Client's charter school customers that access the dashboard.

## 4. Scope of Services

### 4.1 Dashboard Development and Delivery

Provider will deliver a web-based dashboard with secure login for End Client users. Core capabilities include:

1. User authentication and account access controls.
2. Role-based data visibility according to Client-approved rules.
3. Near real-time or scheduled data refresh from source systems.
4. KPI summaries for outreach activity and conversion outcomes.
5. Visualizations showing lead progression from outreach to application.

### 4.2 Dashboard Data and API Services

Provider will:

1. Ingest approved source data from Client systems.
2. Normalize and validate data required for dashboard metrics.
3. Serve dashboard data through Provider-managed API services.
4. Implement monitoring, error handling, and service logging.

### 4.3 Recurring Analytics and Reporting Services

Provider will prepare recurring performance reports that evaluate sales outcomes and lead quality. Reports will include:

1. Lead efficacy by source type (social media, canvassing, and any additional agreed channels).
2. Conversion performance by lead status transitions.
3. Breakdowns by demographic characteristics (as available and permitted).
4. Breakdowns by locational/geographic segments.
5. Recommendations for improving outreach and conversion.

## 5. Functional Requirements (Dashboard)

At minimum, the Dashboard will present:

1. Count of leads contacted by source and date range.
2. Current lead counts by status.
3. Funnel progression from lead creation/contact to application submission.
4. Trend charts for weekly/monthly performance.
5. Filters for date range, lead source, region, and demographic group (where available).

The user interface will include numerical summary cards and charts suitable for non-technical business users.

## Appendix A: Suggested KPI Dictionary (Starter)

1. **Leads Contacted:** Count of unique leads receiving at least one outreach attempt in period.
2. **Source Mix:** Percentage split of leads by source channel.
3. **Contact-to-Qualified Rate:** Qualified leads divided by contacted leads.
4. **Qualified-to-Application Rate:** Applications divided by qualified leads.
5. **Overall Lead-to-Application Conversion:** Applications divided by total leads.
6. **Cycle Time to Application:** Median days from first contact to application submission.

## Appendix B: Suggested Report Template (Starter)

2. Lead source efficacy table and chart.
3. Demographic conversion tables/charts.
4. Location performance heatmap/table.
5. Top drivers of performance and constraints.
6. Recommendations and action plan for next period.
